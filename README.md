One word for the whole internet: **doomscroll**. The endless, doom-laden feed is the internet's dominant mode — funny on its own, true of the whole internet rather than one app, and surprising next to the obvious picks. The program validates the word against the gate rules (1–30 characters, not only whitespace, a single word) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. The output is deterministic: every run writes the same 10 bytes, `doomscroll`.
